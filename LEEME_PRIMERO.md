# Django + Supabase + Vercel — Mac y Windows

Esta es una **continuación** del proyecto de clase original. Conserva la aplicación `estudiantes`, sus modelos, vistas, formularios y migraciones. No incluye contraseñas ni registros reales.

**Orden recomendado:**
1. En Mac: `PASO_A_PASO_MAC.md` (prueba local y Supabase).
2. En Windows: `PASO_A_PASO_WINDOWS.md` (guía original de conexión local).
3. En ambos sistemas: `PASO_A_PASO_VERCEL.md` (GitHub y despliegue).

**Importante:** Vercel publica una aplicación Django en funciones serverless. Para los datos persistentes usa Supabase, nunca SQLite en Vercel. Usa solo datos ficticios: la página demostrativa muestra públicamente la lista de registros.
